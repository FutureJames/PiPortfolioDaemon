    How to use

    Before you start

    Connect the Portfolio (with attached Parallel Interface) to the Pi using an appropriate 25-pin cable. Start the Portfolio's file transfer server mode using the “Setup” menu (or with the keyboard shortcuts: ATARI+S then F then S). If the server is not running, the web page shows “No connection to the Atari Portfolio”.

    Drives

    Use the toggle to switch between A:\ (the removable memory card) and C:\ (the built-in RAM disk). The list shows the files on that drive.

    Folders

    The Portfolio doesn't report folders in its listings, so open one by typing its name in the directory field, e.g. GAMES or GAMES\SAVES, and pressing Enter or Open. Leave it blank for the drive's root. ↰ .. at the top of the list goes up one level. If the folder doesn't exist, the list says “Folder not found”.

    Downloading

    Click a file name to download it from the Portfolio.

    Uploading

    Drop a file onto the upload box, or use Choose file, then Upload. It is sent to the folder shown above the list and replaces any file with the same name. Files can be up to 2 MB. The Portfolio uses short DOS names (8 characters plus a 3-character extension, like NOTES.TXT), so longer names are shortened. If an upload fails, the activity log shows ❌ with the reason and the file is discarded; just upload it again.

    Activity

    Lists uploads (⬆️), downloads (⬇️) and folder changes (📁), with ✅ or ❌ for each one (❌ with the reason, such as a folder that wasn't found). It is shared by everyone using this page and kept until the server restarts. Clear empties it for everyone.

    Connection

    If the page loses its connection to the Pi, a message appears at the bottom and it reconnects by itself. There's no need to reload.
