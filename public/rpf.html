    How to use

    Before you start

    Connect the Portfolio (with attached Parallel Interface) to the Pi using an appropriate 25-pin cable. Start the Portfolio's file transfer server mode using the “Setup” menu (or with the keyboard shortcuts: ATARI+S then F then S). If the server is not running, the web page shows “No connection to the Atari Portfolio” and checks again every 15 seconds; the files appear by themselves once it answers.

    Drives

    Use the toggle to switch between A:\ (the removable memory card) and C:\ (the built-in RAM disk). The list shows the files on that drive. If the memory card is out, the activity log shows ❌ (no card in A:) and the page switches back to C:\.

    Folders

    The Portfolio doesn't report folders in its listings, so open one by typing its name in the directory field, e.g. GAMES or GAMES\SAVES, and pressing Enter or Open. Leave it blank for the drive's root. ↰ .. at the top of the list goes up one level. If the folder doesn't exist, the activity log shows ❌ (folder not found) and the page goes back up to the nearest folder that does.

    Downloading

    Click a file name to download it from the Portfolio. It shows “Downloading…” until the file arrives (roughly 1.5 KB a second). The round download button in the lower right of the list downloads every file in the folder as one .zip (named after the folder, e.g. GAMES.zip).

    Uploading

    Drop one or more files onto the upload box to send them straight away, or use Choose files, then Upload. They are sent to the folder shown above the list and replace any files with the same names. A bar under the buttons counts the files as each one reaches the Portfolio. Files can be up to 2 MB. The Portfolio uses short DOS names (8 characters plus a 3-character extension, like NOTES.TXT), so longer names are shortened. If an upload fails, the activity log shows ❌ with the reason and the file is discarded; just upload it again.

    Activity

    Lists uploads (⬆️), downloads (⬇️) and folder changes (📁), with ✅ or ❌ for each one (❌ with the reason, such as a folder that wasn't found). It is shared by everyone using this page and kept until the server restarts. Clear empties it for everyone.

    If a transfer stops part-way

    If server mode is left or the cable comes out during a transfer, the activity log shows ❌ (the Portfolio stopped answering part-way). Press Esc on the Portfolio (it can take a few seconds) and start server mode again. An interrupted upload may leave a partial copy of the file on the Portfolio. If every transfer fails afterwards while the list still works, restart the Portfolio itself (Ctrl+Alt+Del) and start server mode again.

    Connection

    If the page loses its connection to the Pi, a message appears at the bottom and it reconnects by itself. There's no need to reload.
